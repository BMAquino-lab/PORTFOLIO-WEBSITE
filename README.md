## Steps on How to Create a GitHub Pages Website
1. Create a new repository on GitHub.
2. Add your project files (`index.html`, `style.css`, assets, etc.) to the repository.
3. Go to **Settings** -> **Pages**.
4. Under **Source**, select:
   - Branch: `main`
   - Folder: `/root`
5. Click **Save**.
6. Wait a few minutes for GitHub Pages to deploy your site.
7. Access your website using:  
   `https://<username>.github.io/<repository-name>/`
